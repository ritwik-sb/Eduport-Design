Card

<ep-card>

Groups related content. Three styles: outlined, elevated and filled. Media, header actions and footer are optional.

Variants

Outlined

The default. A border separates it from the page. Open

Elevated

A shadow lifts it off the page. Use for the main item in a view.

Filled

A tinted background with no border. Good for quiet, secondary groups.

Icon

<ep-icon>

Icons from Tabler (over 5,000 available). They size to the text and use its color. The components ship with the set below; apps can register any other Tabler icon.

Alert

<ep-alert>

An inline message about a page or section. Each variant has its own icon, so meaning never depends on color alone.

Variants
The portal will be unavailable on Sunday from 2 to 4 AM. Your teacher will review it by Thursday. Pay before 10 October to avoid a late fee. Pay now Remind me later The file is larger than 25 MB. Compress it and try again. An alert can also be a single line with no heading.

Tooltip

<ep-tooltip>

A short label on hover or focus. Escape closes it, and you can move the pointer onto it without it disappearing.

Modal

<ep-modal>

A dialog for a focused task or a decision. Focus stays inside while it's open and goes back to the button when it closes.
