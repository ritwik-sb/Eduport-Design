Add spacing and layout guidelines and layout tokens. New breakpoints `--ep-breakpoint-{md,lg,xl}` (600, 1024, 1440px) and responsive `--ep-layout-{columns,margin,gutter,section-gap,header-height}` that change inside min-width media queries in `tokens.css`, plus `--ep-layout-sidebar-width` and `--ep-layout-width-{prose,form,page}`. SCSS and JS export the breakpoints for media queries. See docs/layout.md.
